### **NEON FOUR — Connect Four AI**



A neon-themed Connect Four game developed using Python and Pygame.



##### **Features**

\- Play against an AI opponent or another player.

\- Three AI difficulty levels: Easy, Medium, and Hard.

\- AI decision-making using Minimax with Alpha-Beta Pruning.

\- Detects horizontal, vertical, and diagonal wins.

\- Scoreboard and restart functionality.

\- Dark interface with neon-pink and cyan colours.



##### **Technologies Used**

\- Python

\- Pygame

\- Minimax Algorithm

\- Alpha-Beta Pruning



##### **Installation**



1\. Install Python.

2\. Install Pygame:



&#x20;  'pip install pygame'



3\. Run the game:



&#x20;  'python neon.py'

##### 

##### **How to Play**

Click a column to drop a disc. Connect four discs in a row to win.

##### 

##### **AI Algorithm**

The AI evaluates possible moves using Minimax and Alpha-Beta Pruning to choose strategic moves.



##### **Project Purpose**

This project demonstrates traditional Artificial Intelligence through a strategy-based board game.
